# 01-Public-Bot-Apps: Sector-Specific AI Chatbots

This directory contains lightweight, public-facing web applications designed to simulate external AI consumption across different industry verticals. 

As public interfaces exposed to unauthenticated users, these applications represent the highest risk surface for **Denial of Wallet (DoW)** attacks, **Prompt Injection**, and **Data Exfiltration**. They serve as the perfect testing ground for partners to demonstrate Prisma AIRS capabilities in action.

### Deployed Verticals

*   `/app/retail` - Simulates a retail customer service and inventory chatbot.
*   `/app/finance` - Simulates a banking assistant handling sensitive queries.
*   `/app/industry` - Simulates a manufacturing or technical support agent.
